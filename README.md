# 🌸 QQ 群大模型管理工具插件 (`astrbot_plugin_qq_group_admin`)

一款专门为 **AstrBot** 注册原生大模型工具（LLM Tool）的轻量级 QQ 群管理插件。无需记忆任何死板的前缀或正则表达式命令，让大模型直接理解群管理员的自然语言诉求（如“把小明禁言5分钟”、“把某某踢出群聊并拉黑”、“撤回这条消息”、“设为群精华”），并自动安全地调用底层 OneBot API 执行相关群管操作。

---

## ✨ 核心特性

1. **大模型原生 Tool 支持**：
   - `ban_group_member`：对指定群成员执行禁言或解除禁言。
   - `kick_group_member`：将指定群成员移除群聊（踢人），支持是否同时拒绝后续加群申请（拉黑/黑名单）。
   - `delete_group_message`：撤回指定消息，支持回复/引用消息时自动识别并撤回。
   - `set_group_essence_message`：设置或取消群精华消息，支持回复/引用消息时自动识别并设为精华/移除精华。
2. **灵活的三级权限控制开关**：
   - `allow_bot_admin`：是否允许 Bot 配置文件中指定的超级管理员使用（默认 `true`）。
   - `allow_group_owner`：是否允许目标群的群主使用（默认 `true`）。
   - `allow_group_admin`：是否允许目标群的管理员使用（默认 `true`）。
3. **安全严密防护**：工具被大模型触发时，会在函数底层二次强校验发送者的实际身份，防止普通群成员越权使用自然语言命令。
4. **友好的异常反馈**：若 Bot 自身在群内缺乏管理员权限或 API 调用失败，大模型能获得清晰明确的回执说明。

---

## ⚙️ 配置说明

在 AstrBot 管理面板的插件配置页面中，支持配置以下 3 个权限开关：

| 配置项 (Key) | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `allow_bot_admin` | bool | `true` | 是否允许 **Bot 超级管理员**（`admins_id` 列表中的账号）使用管理工具 |
| `allow_group_owner` | bool | `true` | 是否允许**目标群群主**使用管理工具 |
| `allow_group_admin` | bool | `true` | 是否允许**目标群管理员**使用管理工具 |

## 🚀 使用方法与指令范例

插件无需注册任何死板的前缀命令。只要当前发送者满足上述配置开关中的任一权限，在 QQ 群聊中直接对 Bot 提出自然语言要求即可：

### 1. 禁言与解禁（`ban_group_member`）
- **常规禁言**：“把 [at:12345678] 禁言 5 分钟” / “给 12345678 套餐半小时”
- **解除禁言**：“把 [at:12345678] 放出来” / “解除 12345678 的禁言”
- **带原因禁言**：“把 [at:12345678] 禁言 10 分钟，原因：刷屏打广告”

### 2. 踢出群聊（`kick_group_member`）
- **常规踢人**：“把 [at:12345678] 踢出群聊” / “把 12345678 移出本群”
- **踢人并拉黑**：“把 [at:12345678] 踢出去，并且拒绝他再申请加群” / “把 12345678 移除群聊并拉黑”
- **带原因踢人**：“把 [at:12345678] 踢了，原因：违规言论”

### 3. 撤回消息（`delete_group_message`）
- **引用撤回**：（回复/引用某条违规消息）“把这条消息撤回” / “撤回他刚才发的内容”
- **指定 ID 撤回**：“撤回消息 123456789”

### 4. 群精华消息（`set_group_essence_message`）
- **引用设为精华**：（回复/引用某条优质消息）“把这条设为精华” / “设为群精华消息”
- **引用取消精华**：（回复/引用某条已设为精华的消息）“取消精华” / “把这条消息移除群精华”
- **指定 ID 设精华**：“把消息 123456789 设为精华”

## ❓ 常见问题 (FAQ)

1. **为什么提示“Bot 自身在群中缺乏管理员权限”？**
   - 实际在 QQ 服务端执行禁言、踢人、撤回和设置精华动作的是 **Bot 账号自身**。因此，请确保 Bot 账号在当前 QQ 群中拥有**管理员**或**群主**身份。

2. **为什么我是 Bot 管理员但在群里是普通成员也能成功使用？**
   - 只要配置中的 `allow_bot_admin` 开启，且你的 QQ 号登记在 AstrBot `全局配置` -> `admins_id` 列表中，插件内部就会识别并授权。只要 Bot 账号自身在群里是管理员，即可成功执行操作！
